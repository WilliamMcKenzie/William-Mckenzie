HTML5 Canvas Art

This is a little bit of a follow-along HTML5 procedural canvas pixel art tutorial. It makes for wild websites with instant load times, using pure math instead of massive frameworks.

Canvas Intro

Procedural art is art that has been created with a system instead of by hand. No not like AI! The system is the art itself, usually derived from math functions.

You can find an example on the main page of my website, but first we need to get a canvas set up and display math functions on it. To start off, I'm going to establish some functions; toPixel(x), getPoint(x), and animate().

Added:
  • pixel: The size of each pixel in our grid.
  • height: Height of our sin wave.
  • period: Period of our sin wave.
  • canvas: Our canvas element from the html document.
  • context: Our canvases context, which allows us to draw.
  • toPixel(x): Snap any number into a grid.
  • getPoint(x): To get the y value for a given x value, our function.
  • animate(): The core loop which will get repeatedly called.

function toPoint(x) {
    const value = Math.sin(x / period) * height
    return value + height
}

function animate() {
    const width = canvas.width
    for (let x = 0; x < width; x++) {
        context.fillRect(toPixel(x), toPixel(toPoint(x)), pixel, pixel)
    }

    requestAnimationFrame(animate)
}

Animation

Cool! But how do we make it oscillate? We can simply add a counter to the animation loop. With this new dynamic counter, add it to both shift and act as a coefficient to our sin function.

Added:
  • speed: How fast the counter goes up.
  • counter: Count how many frames we have been through.
